ETL Checklist — CEDS Mapping

Upload your data dictionary (.csv or .xlsx) to automatically map its elements and option set values to CEDS. Review each suggestion, accept or override it, then export the completed ETL Checklist.

File Requirements

  • File type: .xlsx, .xls, or .csv. Only the first worksheet of an Excel file is read.
  • Header row: must appear within the first 10 rows of the sheet and contain a column recognized as the element name (see below). Rows above the header row are ignored, so a title row is fine.
  • Column matching is forgiving: capitalization, spacing, and punctuation in headers are ignored (for example, "Element/Field Name" and "element field name" both match). Column order does not matter, and unrecognized columns are ignored.
  • One row per option set value: if an element has an option set (enumeration), repeat the element on one row per value and vary only the option set code/description columns. All rows with the same Element Name are listed as a single element (duplicate option values are ignored).
  • Elements without an option set use a single row with the option set columns left blank.
